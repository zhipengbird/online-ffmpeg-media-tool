## 1. 产品简介

**在线 FFmpeg 工具箱**是一个无需安装、打开网页即可使用的音视频与图片处理工具。它把业界广泛使用的开源多媒体引擎 FFmpeg 搬到了浏览器中运行，精简收敛为 **12 项场景化超级功能**，操作更便捷，避免多步繁琐切换：

- 🎬 **视频**：视频转码与压制（格式+CRF+分辨率+静音一体）、视频剪辑与调速（毫秒裁剪+变速+旋转）、转 GIF、精准截图、配乐与替换音轨、图片转视频
- 🎵 **音频**：全能音频工坊（格式转换、提取音轨、起止剪切、音量缩放、淡入淡出）
- 🖼️ **图片**：全能图片工坊（格式转换、画质压缩、尺寸缩放、旋转镜像、艺术滤镜、清除隐私元数据）、智能证件照制作、自由/比例裁剪、批量图片水印、多图横纵拼接

**核心优势**

| 优势 | 说明 |
| --- | --- |
| 隐私安全 | 文件只在您自己的电脑 / 手机中处理，**不会上传**到任何服务器 |
| 无需安装 | 打开网页即可使用，不占用磁盘空间 |
| 离线可用 | 首次打开后，核心组件已包含在页面中，无需额外下载 |
| 操作直观 | 左侧选择功能，上传文件，调整参数，点击开始即可 |
| 链式处理 | 处理结果可直接作为下一步的输入 |

## 2. 运行环境

| 项目 | 要求 |
| --- | --- |

## 4. 基本操作流程

```
① 选择功能  →  ② 上传文件  →  ③ 调整参数  →  ④ 开始处理  →  ⑤ 预览 / 下载
```

**步骤详解**

1. **选择功能**：在左侧菜单点击需要的功能，例如"视频压缩"。
2. **上传文件**：
   - 点击虚线框选择文件，或直接把文件拖进虚线框；
   - 支持的格式见各功能说明。部分功能需要两个文件（如"音视频合并"），页面会分别显示两个上传框。
   - 上传后，系统会自动读取文件信息（时长、分辨率等），稍等片刻即可。
3. **调整参数**：参数有默认值，可以直接使用；需要时再修改。
4. **开始处理**：点击 **"▶ 开始处理"**。进度条会显示进度，处理期间请保持页面打开。
5. **预览与下载**：
   - 处理完成后，结果区会显示预览；视频、音频可直接播放，图片可直接查看；
   - 点击 **"⬇️ 下载"** 保存文件，默认文件名格式为 `原文件名-功能名.扩展名`；
   - 在 **"🔁 作为输入，继续处理"** 区域，会列出所有能接收该文件类型的工具（如输出 MP4 后可选择"视频压缩""视频转 GIF"等）。点击某个工具，页面会自动切换到该工具并载入此文件；当前工具会以深色按钮标注"（当前）"。
   - 不支持的类型不会出现在列表中。若手动拖入类型不符的文件，页面会提示"不是 xx 支持的文件类型"，并保留原有文件。

**取消任务**：处理中点击 **"取消"** 即可中止。取消后引擎会在后台自动重新加载，约需数秒。

## 5. 功能详解

> 说明：表中"默认值"为打开页面时的初始设置；"范围"为可调整的取值区间。

### 5.1 视频处理

#### 🔄 视频格式转换

将视频转换为其他容器格式，画面与声音会重新编码。

- **输入**：视频文件（MP4、MKV、MOV、AVI、WebM、FLV、TS、M4V、3GP、WMV 等）
- **输出**：与所选格式一致的视频文件

| 参数 | 默认值 | 可选 / 范围 | 说明 |
| --- | --- | --- | --- |
| 输出格式 | MP4 | MP4、MOV、MKV、WebM、AVI、FLV | MP4 兼容性最好，推荐日常使用 |
| 画质（CRF） | 23 | 0 ～ 51 | 数值越小画质越好、文件越大；18～28 为常用范围 |

> 提示：输出为 WebM 时使用 VP8 + Opus 编码，耗时通常比 MP4 更长。

#### 🗜️ 视频压缩

通过重新编码降低文件体积，可同时降低分辨率与音频码率。

- **输入**：视频文件
- **输出**：MP4（H.264 + AAC）

| 参数 | 默认值 | 可选 / 范围 | 说明 |
| --- | --- | --- | --- |
| 压缩强度（CRF） | 28 | 18 ～ 40 | 数值越大体积越小、画质越低；26～32 为推荐范围 |
| 编码速度 | veryfast | ultrafast、veryfast、faster、medium、slow | 越慢压缩率越高，但耗时明显增加 |
| 输出高度 | 720p | 保持原始、1080p、720p、480p、360p | 降低分辨率是最有效的减小体积方式 |
| 音频码率 | 96 kbps | 64、96、128 kbps | 语音类视频 64～96 kbps 已足够 |

#### 📐 视频分辨率调整

自定义输出的宽度与高度。

- **输入**：视频文件
- **输出**：MP4

| 参数 | 默认值 | 范围 | 说明 |
| --- | --- | --- | --- |
| 宽度 | 0 | 0 ～ 7680 像素 | 填 **0** 表示按比例自动计算 |
| 高度 | 720 | 0 ～ 4320 像素 | 填 **0** 表示按比例自动计算 |

> 提示：宽高至少填写一项。若两项都填，画面会被拉伸到指定尺寸，可能变形；若只填一项，比例会自动保持。

#### 🔁 视频旋转 / 翻转

| 操作 | 效果 |
| --- | --- |
| 顺时针旋转 90° | 竖屏拍摄的横向视频常用 |
| 逆时针旋转 90° | 同上，方向相反 |
| 旋转 180° | 画面上下颠倒时使用 |
| 水平翻转 | 左右镜像 |
| 垂直翻转 | 上下镜像 |

- **输入 / 输出**：视频文件 → MP4

#### ✂️ 视频剪切

截取视频中的一段。

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| 开始时间 | 0 秒 | 单位：秒（可输入小数，如 12.5） |
| 结束时间 | 0 | 填 **0** 表示剪到视频末尾 |
| 剪切模式 | 精确剪切 | 见下表 |

| 模式 | 特点 | 适用场景 |
| --- | --- | --- |
| 精确剪切（重新编码） | 剪切点精确，画质可控，速度较慢 | 需要精准截取的情况（默认推荐） |
| 快速剪切（直接复制流） | 几乎瞬间完成，不损失画质 | 只需粗略截取，且可接受起止点有少量偏差 |

> 提示：快速剪切只能从关键帧处开始，起点可能会比设定的时间略早或略晚。

#### ⏩ 视频变速

加快或放慢视频播放速度。

- **输入 / 输出**：视频文件 → MP4
- **速度选项**：0.25x、0.5x、0.75x、1.25x、1.5x、2x（默认）、3x、4x
- 若视频包含声音，声音会同步变速，且音调保持自然（不会变尖或变粗）。

#### 🎞️ 视频转 GIF

把视频片段转换为动图，适合表情包、演示动画。

| 参数 | 默认值 | 范围 | 说明 |
| --- | --- | --- | --- |
| 开始时间 | 0 秒 | ≥ 0 | 片段起点 |
| 持续时长 | 5 秒 | 0 = 整个视频 | **不建议**对长视频使用 0，文件会非常大 |
| 帧率（FPS） | 10 | 1 ～ 30 | 越高越流畅，文件越大 |
| 宽度 | 480 px | 16 ～ 1920 | 高度按比例自动计算 |

> 提示：GIF 体积增长很快。建议控制在 **5 秒、10 FPS、480 px 宽** 以内。

#### 🔇 去除音轨（静音）

删除视频中的声音，画面保持不变，且**不重新编码**，处理速度很快。

- **输入**：视频文件
- **输出格式**：MP4 或 MKV

#### 📸 视频截图

截取视频某一时刻的画面，保存为图片。

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| 截取时间点 | 1 秒 | 单位：秒 |
| 图片格式 | PNG | PNG（无损）、JPG、WebP |

#### 🖼️ 图片转视频

把一张图片变为一段静止画面的视频，可用于制作封面视频或幻灯片素材。

- **输入**：图片文件（JPG、PNG、WebP、BMP、GIF、TIFF）
- **输出**：MP4

| 参数 | 默认值 | 范围 | 说明 |
| --- | --- | --- | --- |
| 视频时长 | 5 秒 | 0.1 ～ 3600 | 画面持续时间 |
| 帧率（FPS） | 25 | 1 ～ 60 | 静态画面对帧率不敏感，保持默认即可 |

#### 🔗 音视频合并（替换音轨）

把一段音频作为新的声音，合并到视频画面中。**原视频的声音会被替换**。

- **输入**：两个文件 —— ① 视频（提供画面）② 音频（提供新声音）
- **输出**：MP4，画面不重新编码

| 参数 | 默认值 | 可选 | 说明 |
| --- | --- | --- | --- |
| 音频码率 | 192 kbps | 128、192、256 kbps | 音质要求高可选 256 kbps |

> 提示：以较短的一方为准截止。例如音频 30 秒、视频 60 秒，输出为 30 秒。

### 5.2 音频处理

#### 🔊 音频格式转换 / 提取音轨

- **输入**：音频文件，**或直接上传视频**（将自动提取其中的声音）
- **输出**：音频文件

| 参数 | 默认值 | 可选 | 说明 |
| --- | --- | --- | --- |
| 输出格式 | MP3 | MP3、M4A（AAC）、WAV、FLAC、OGG、OPUS | 见下表 |
| 码率 | 192 kbps | 96、128、192、256、320 kbps | 仅对 MP3、M4A、OGG、OPUS 有效 |

| 格式 | 类型 | 推荐用途 |
| --- | --- | --- |
| MP3 | 有损，兼容性最好 | 通用分享 |
| M4A（AAC） | 有损，同码率下音质更好 | 苹果设备、音乐 |
| WAV | 无损，文件很大 | 后期编辑 |
| FLAC | 无损，体积比 WAV 小 | 音乐存档 |
| OGG / OPUS | 有损，高效 | 网页、游戏 |

#### ✂️ 音频剪切 / 音量 / 淡入淡出

同时完成剪切、调音量和淡入淡出，一次输出。

- **输入**：音频文件，或视频（提取声音）

| 参数 | 默认值 | 可选 / 范围 | 说明 |
| --- | --- | --- | --- |
| 开始时间 | 0 秒 | ≥ 0 | 截取起点 |
| 结束时间 | 0 | 0 = 到末尾 | 截取终点 |
| 音量 | 100% | 50%、80%、100%、150%、200%、300% | 超过 100% 可能产生失真 |
| 淡入时长 | 0 秒 | ≥ 0 | 开头逐渐变大声的时长 |
| 淡出时长 | 0 秒 | ≥ 0 | 结尾逐渐变小声的时长（需要已知音频时长） |
| 输出格式 | MP3 | MP3、M4A、WAV、FLAC | — |
| 码率 | 192 kbps | 128、192、320 kbps | 仅对 MP3、M4A 有效 |

> 提示：常见用法是设置淡出 2～3 秒，让背景音乐结尾更自然。

### 5.3 图片处理

#### 🔁 图片格式转换

- **输入**：PNG、JPG、WebP、BMP、GIF、TIFF 等图片
- **输出**：所选格式的图片

| 参数 | 默认值 | 可选 | 说明 |
| --- | --- | --- | --- |
| 输出格式 | PNG | PNG、JPG、WebP、BMP、GIF | PNG 支持透明背景；JPG 不支持透明 |
| 质量 | 90 | 1 ～ 100 | 仅 JPG、WebP 有效；数值越高越清晰、文件越大 |

#### 🗜️ 图片压缩 / 缩放

调整尺寸并降低质量，减小文件体积。推荐先选择**常用预设**，再按需微调。

**第一步：选择常用预设**（点击卡片即可一次性套用全部参数）

| 预设 | 效果 |
| --- | --- |
| 朋友圈 / 社交媒体（默认） | 宽 1080，JPG，质量 80 |
| 网站配图 | 宽 1200，WebP，质量 80 |
| 邮件附件（小体积） | 宽 800，JPG，质量 65 |
| 缩略图（正方形） | 300×300，1:1 居中裁剪，WebP，质量 75 |
| 头像 | 512×512，1:1 居中裁剪，JPG，质量 90 |
| 视频封面（横版） | 1920×1080，16:9 居中裁剪，JPG，质量 85 |
| 竖版海报 | 1080×1920，9:16 居中裁剪，JPG，质量 85 |
| 无损 PNG（仅缩放） | 保持原尺寸，PNG 无损 |
| 自定义 | 不套用预设，完全手动设置下方参数 |

> 提示：修改任一参数后，预设卡片会自动切换为"自定义"（若修改后的参数恰好与某个预设一致，则会选中该预设）。

**第二步：自定义参数**

| 参数 | 默认值 | 可选 / 范围 | 说明 |
| --- | --- | --- | --- |
| 宽高比 | 原始比例 | 原始比例、1:1、4:3、3:2、16:9、9:16 | 选择目标比例后，只填宽或只填高，另一边自动按比例计算 |
| 裁剪方式 | 居中裁剪（填满） | 居中裁剪、等比缩放（不裁剪） | 仅在选择了宽高比时显示。裁剪会填满目标尺寸；等比缩放则完整保留画面，输出尺寸可能略小 |
| 宽度 | 1080 | 0 ～ 16000 px | 0 = 按比例自动计算 |
| 高度 | 0 | 0 ～ 16000 px | 0 = 按比例自动计算 |
| 不放大图片 | 开 | 开 / 关 | 开启时，目标尺寸大于原图则保持原分辨率，避免模糊 |
| 输出格式 | JPG | JPG、WebP、PNG | JPG / WebP 压缩效果最好；PNG 无损但体积较大 |
| 质量 | 80 | 1 ～ 100 | 仅 JPG、WebP 有效；70～80 通常肉眼难以分辨差异 |

**输出尺寸提示**：参数区下方会实时显示预估的输出尺寸（例如"居中裁剪为 1:1，输出 300×300"），便于在处理前确认效果。

**第三步：批量处理**

1. 在文件区点击选择，或一次框选 / 拖拽多张图片（同一批可混合 JPG、PNG、WebP 等格式）。
2. 每添加一张，系统会读取它的尺寸；列表中可查看每张图片的大小和分辨率，点击"移除"可删除单张，点击"清空列表"可全部删除。
3. 设置好预设或参数后，点击 **"▶ 开始批量处理（N 张）"**。图片会按列表顺序逐张处理，进度条显示"正在处理第 k / N 张"。
4. 处理完成后，结果列表会显示每张图片的缩略图、压缩前后大小和压缩比例，并给出总体节省情况（如"节省 62%"）。
5. 可逐张点击 **"下载"**，也可点击 **"📦 打包下载 ZIP"** 一次性获取全部结果。同名文件会自动加序号（如 `a.jpg`、`a-1.jpg`）。

> 注意：
> - 批量处理时，裁剪、宽高比、不放大等规则对每张图片**分别**生效，各自按原始尺寸计算。

## 8. 常见问题 FAQ

**Q1：为什么第一次打开比较慢？**
A：页面内嵌了完整的音视频处理引擎（约 43 MB），首次打开需要解析，通常需要几秒到十几秒。之后浏览器会缓存，再次打开会快很多。

**Q2：上传后为什么没有显示时长和分辨率？**
A：系统正在读取文件信息，请稍等几秒。若长时间没有显示，可能是文件已损坏或格式不受支持，可尝试换一个文件或用其他播放器确认文件可正常播放。

**Q3：处理需要多久？**
A：取决于文件大小、功能和您的设备性能。经验参考：1 分钟 1080p 视频的"视频压缩"在普通笔记本上约需数分钟。"去除音轨"等不重新编码的功能则几乎瞬间完成。

**Q4：可以同时处理多个文件吗？**
A：目前一次处理一个任务。完成一个后，可以再上传下一个文件开始新任务。

**Q5：处理后的文件变大了，为什么？**
A：通常是因为输出格式为无损（WAV、PNG），或把有损格式（JPG）转换为了高质量设置。尝试降低质量参数，或选择压缩类功能。

**Q6：支持加密文件或 DRM 视频吗？**
A：不支持。受 DRM 保护的视频（如流媒体平台下载的内容）无法处理。

**Q7：支持中文文件名吗？**
A：支持。输出文件会沿用原文件名并附加功能后缀。

**Q8：为什么视频剪切后开头有一小段黑屏或画面跳动？**
A：使用"快速剪切"时，起点只能对齐到关键帧，可能出现偏差。改用"精确剪切"即可解决。

**Q9：手机上可以使用吗？**
A：可以，但手机内存有限，建议只处理小于 50 MB 的文件。

**Q10：为什么没有声音？**
A：请确认：① 输入视频本身有声音（在文件信息中查看"含音轨"）；② 使用的是"去除音轨"时，输出本来就是无声的。

## 9. 故障排查

### 9.1 顶部显示"FFmpeg 加载失败"

1. 点击顶部的 **"重试"** 按钮。
2. 刷新页面（F5 或 Cmd+R）。
3. 更换为 Chrome 或 Edge 的最新版本。
4. 若仍失败，请记录页面红色横幅中的错误信息，联系技术支持。

### 9.2 长时间停留在"正在初始化"或"正在加载 FFmpeg 核心"

这通常是设备性能或内存不足导致的：

1. 关闭其他浏览器标签页和占用内存较多的程序。
2. 等待数十秒，系统会在 **120 秒后** 给出超时提示。
3. 超时后点击 **"重试"**。
4. 仍不行时，尝试 **无痕窗口**（可避免浏览器扩展干扰）或更换浏览器。
5. 手机端可尝试重启浏览器，或换用电脑。

### 9.3 处理失败，出现红色错误提示

错误信息中可能包含以下内容，可据此判断原因：

| 错误提示 | 含义 | 处理方法 |
| --- | --- | --- |
| `Invalid data found when processing input` | 文件损坏或格式不支持 | 换一个文件，或先用播放器确认文件可播放 |
| `Unknown encoder` | 该输出格式在当前版本中不可用 | 换用其他输出格式（如 MP4） |
| `Output file ... does not contain any stream` | 输入不包含所需的声音或画面 | 例如对无声视频提取音频，属正常提示 |
| `Option loop not found` | 图片转视频的输入不是图片（例如误把 MP4 作为输入） | 新版本已禁止此操作；请选择 PNG / JPG / WebP 等图片作为输入 |
| `图片转视频只接受图片文件作为输入` | 同上，新版本给出的中文提示 | 同上 |
| `结束时间必须大于开始时间` | 时间设置有误 | 修改结束时间 |
| `开始时间超出视频时长` | 起点超过视频总长 | 减小开始时间 |
| `无法获取音频时长` | 文件信息读取失败 | 重新上传文件 |

### 9.4 处理中途页面卡住

- 大文件转码耗时较长属正常现象，请耐心等待，**不要关闭页面**。
- 若进度条长时间不动，可点击 **"取消"**，然后降低分辨率、缩短时长后重试。
