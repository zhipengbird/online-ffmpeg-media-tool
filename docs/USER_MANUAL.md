## 1. 产品简介

**在线 FFmpeg 工具箱**是一个无需安装、打开网页即可使用的音视频与图片处理工具。它把业界广泛使用的开源多媒体引擎 FFmpeg 搬到了浏览器中运行，精简收敛为 **14 项场景化超级功能**，操作更便捷，避免多步繁琐切换：

- 🎬 **视频**：视频转码与压制（格式+CRF+分辨率+静音一体，**支持多视频批量压制与打包下载**）、视频剪辑与调速（毫秒裁剪+变速+旋转）、转 GIF、视频抽帧 / 联系表、配乐与替换音轨、图片动态封面视频
- 🎵 **音频**：全能音频工坊（格式转换、提取音轨、起止剪切、音量缩放、淡入淡出，**支持批量处理**）
- 🖼️ **图片**：图片编辑器 / 全能图片工坊、图片转 GIF 动图、Meme 生成器、智能证件照制作、自由/比例裁剪、批量图片水印、多图横纵拼接（**支持 2~30 张多图自由拼长图/横幅，支持自定义顺序调整**）

**核心优势**

| 优势 | 说明 |
| --- | --- |
| 隐私安全 | 文件只在您自己的电脑 / 手机中处理，**不会上传**到任何服务器 |
| 无需安装 | 打开网页即可使用，不占用磁盘空间 |
| 离线可用 | 首次打开后，核心组件已包含在页面中，无需额外下载 |
| 操作直观 | 左侧选择功能，上传文件，调整参数，点击开始即可 |
| 链式处理 | 处理结果可直接作为下一步的输入 |

## 2. 运行环境

| 项目 | 要求 |
| --- | --- |
| 浏览器 | Chrome、Edge、Firefox、Safari 的最新版本（推荐 Chrome / Edge） |
| 操作系统 | Windows、macOS、Linux、Android、iOS 均可 |

## 4. 基本操作流程

```
① 选择功能  →  ② 上传文件  →  ③ 调整参数  →  ④ 开始处理  →  ⑤ 预览 / 下载
```

**步骤详解**

1. **选择功能**：在左侧菜单点击需要的功能，例如"视频压缩"。
2. **上传文件**：
   - 点击虚线框选择文件，或直接把文件拖进虚线框；
   - 支持的格式见各功能说明。部分功能需要两个文件（如"音视频合并"），页面会分别显示两个上传框。
   - 上传后，系统会自动读取文件信息（时长、分辨率等），稍等片刻即可。
3. **调整参数**：参数有默认值，可以直接使用；需要时再修改。
4. **开始处理**：点击 **"▶ 开始处理"**。进度条会显示进度，处理期间请保持页面打开。
5. **预览与下载**：
   - 处理完成后，结果区会显示预览；视频、音频可直接播放，图片可直接查看；
   - 点击 **"⬇️ 下载"** 保存文件，默认文件名格式为 `原文件名-功能名.扩展名`；
   - 在 **"🔁 作为输入，继续处理"** 区域，会列出所有能接收该文件类型的工具（如输出 MP4 后可选择"视频压缩""视频转 GIF"等）。点击某个工具，页面会自动切换到该工具并载入此文件；当前工具会以深色按钮标注"（当前）"。
   - 不支持的类型不会出现在列表中。若手动拖入类型不符的文件，页面会提示"不是 xx 支持的文件类型"，并保留原有文件。

**取消任务**：处理中点击 **"取消"** 即可中止。取消后引擎会在后台自动重新加载，约需数秒。

## 5. 功能详解

> 说明：表中"默认值"为打开页面时的初始设置；"范围"为可调整的取值区间。

### 5.1 视频处理（共 6 项）

#### 🎬 1. 视频转码与压制（支持批量处理）

格式转换、CRF 画质压制、分辨率缩放与静音处理一站式完成，适合大视频瘦身、格式互转与网页分享。

- **输入**：视频文件（支持 MP4、MKV、MOV、AVI、WebM、FLV、TS、M4V 等格式；可批量多选）
- **输出**：所选格式的视频文件

**常用预设**（点击卡片即可一键套用）：

| 预设卡片 | 效果与参数 | 推荐用途 |
| --- | --- | --- |
| 保持原画 | 原分辨率 · CRF 22 · MP4 | 格式转换，画质几乎无损 |
| 标准压缩（默认） | 720p · CRF 26 · MP4 | 兼顾清晰度与体积，日常分享推荐 |
| 高清压制 | 1080p · CRF 23 · MP4 | 高清播放，压制后细节饱满 |
| 极小体积 | 480p · CRF 30 · MP4 | 邮件附件、弱网传输、文字演讲视频 |
| WebM 网页分享 | 720p · VP9 编码 · WebM | 适合嵌入网页与免专利流媒体播放 |
| 自定义 | 手动自由组合下方参数 | 专业用户精细微调 |

**自定义参数说明**：

| 参数 | 默认值 | 可选 / 范围 | 说明 |
| --- | --- | --- | --- |
| 输出格式 | MP4 (H.264 + AAC) | MP4、WebM (VP9)、MOV、MKV、AVI | MP4 兼容性最好；WebM 压缩率更高 |
| 压缩画质（CRF） | 26 | 0 ～ 51 | 数值越小画质越好、文件越大；推荐 20～28 |
| 输出分辨率 | 720p (1280x720) | 保持原尺寸、1080p、720p、480p、360p | 降低分辨率是缩减体积最显著的方式 |
| 去除音频轨道 | 关 | 开 / 关 | 开启后消除声音，输出无声音轨的纯画面视频 |

**批量压制与多媒体预览特性**：
- 支持一次拖入多个不同格式与分辨率的视频；
- **智能缩略图感知**：队列完成项自动抓取视频首帧并叠加 `▶` 播放角标，彻底杜绝图片裂图；
- **极速内联播放器**：单任务压缩完成时直接在顶部展开交互式 `<video controls>` 播放器，并直观对比压缩前后体积与节省比例；
- **全屏模态预览**：每项均提供「▶ 播放」专属按钮，点击展开带进度条与全屏按钮的大弹层，支持键盘 `ESC` 随时关闭；
- **一键打包**：提供「📦 打包下载 ZIP」，一键批量导出处理完成的文件。

#### ✂️ 2. 视频剪辑与调速

将精确时间裁剪、0.25~4x 倍速播放以及画面镜像旋转三项高频需求合为一体。

- **输入**：视频文件
- **输出**：MP4 视频文件

**可视化时间轴辅助与打点试看**：
- **拖拽与微调**：内置交互式时间滑轨，支持鼠标长按拖拽、点击跳转，并支持方向键（`←`/`→`，按住 `Shift` 步进 1s）毫秒级微调当前帧；
- **一键时间打点**：提供「📍 设为开始时间」与「🏁 设为结束时间」，边播放边精准标记剪辑范围，无需心算秒数；
- **选区试看预览（▶ 试看所选片段）**：点击后播放器会自动从开始点精准播放至结束点并自动停止，在导出之前即可确认截取片段是否严丝合缝；
- **起止跳转**：支持「⏮ 跳至开始」与「⏭ 跳至结束」一键核验打点边界画面。

| 参数 | 默认值 | 可选 / 范围 | 说明 |
| --- | --- | --- | --- |
| 开始时间 | 0 秒 | ≥ 0（支持小数，如 12.5） | 剪辑起点 |
| 结束时间 | 0 秒 | 0 = 截取到视频末尾 | 剪辑终点 |
| 播放速度 | 1x（正常） | 0.25x、0.5x、0.75x、1x、1.25x、1.5x、2x、3x、4x | 声音会同步变调处理，保持人声音调自然真实 |
| 画面旋转 / 翻转 | 保持原样 | 水平翻转（镜像）、垂直翻转、顺时针90°、逆时针90°、旋转180° | 纠正手机竖拍横屏或前置镜头镜像画面 |

#### 🎞️ 3. 视频转 GIF 动图

基于 FFmpeg `palettegen` 算法智能两阶段分析提取最优调色板，杜绝传统转换中容易出现的杂色斑点与严重噪点。

- **输入**：视频文件
- **输出**：高清 GIF 动图

| 参数 | 默认值 | 范围 | 说明 |
| --- | --- | --- | --- |
| 开始时间 | 0 秒 | ≥ 0 | 截取动图的起点 |
| 持续时长 | 5 秒 | 0.1 ～ 60 秒 | 动图长度，建议 3～8 秒以内 |
| 帧率（FPS） | 12 | 1 ～ 30 | 越高越流畅、文件越大；10～15 FPS 适合表情包 |
| 动图宽度 | 480 px | 64 ～ 1920 px | 高度按比例自适应计算 |

#### 📸 4. 视频抽帧 / 联系表

可在视频指定时间点截取单帧封面，也可以按时间间隔抽取多帧并排成联系表，适合快速选封面、审片和查看关键画面。

- **输入**：视频文件
- **输出**：PNG、JPG 或 WebP 图片

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| 抽帧方式 | 单帧封面 | 可选单帧封面或多帧联系表 |
| 截取时间点 | 1 秒 | 单帧模式使用，支持毫秒级小数（如 3.65） |
| 抽帧间隔 | 2 秒 | 联系表模式使用，范围 0.1～60 秒 |
| 最多帧数 | 6 帧 | 联系表模式使用，最多 30 帧 |
| 输出格式 | PNG（无损） | 可选 PNG（无损画质）、JPG（通用照片）、WebP（高压缩比） |

#### 🎵 5. 视频配乐 / 替换音轨

将新的外部音频合成替换为视频的伴奏音乐，画面不进行重新编码（保持无损极速处理）。

- **输入**：双输入 —— ① 视频文件（提供画面）② 音频文件（提供声音）
- **输出**：MP4 视频文件（原视频原有音轨将被替换，若音频长度不同自动平齐）

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| 音频编码码率 | 192 kbps | 可选 128、192、256、320 kbps |

#### 🖼️ 6. 图片动态封面视频

将 1～30 张图片按列表顺序制作成适合短视频发布的动态封面视频，支持横屏、竖屏和正方形画幅，并可组合镜头运动、色彩风格、转场和背景音乐。

- **输入**：JPG、PNG、WebP、BMP、GIF 等图片；可选添加一条本地音频作为背景音乐
- **输出**：MP4 视频文件

| 参数 | 默认值 | 范围 | 说明 |
| --- | --- | --- | --- |
| 每张图片时长 | 5 秒 | 0.1 ～ 3600 秒 | 每张图片在视频中的持续时间 |
| 帧率（FPS） | 25 | 1 ～ 60 | 静态画面 25 FPS 已十分平滑 |
| 视频画幅 | 原图比例 | 原图、横屏 16:9、竖屏 9:16、正方形 1:1 |
| 画面适配 | 铺满画面 | 目标画幅下可选择裁切铺满或完整显示 |
| 动态效果 | 静止画面 | 静止、缓慢放大/缩小、向左/右/上/下平移 |
| 画面风格 | 原图色彩 | 原图、鲜艳增强、黑白、暖调、冷调、复古棕褐 |
| 图片转场 | 直接切换 | 直接切换、淡入淡出、左右滑动、左右擦除、圆形展开 |
| 背景音乐 | 不添加 | 可选择本地音频，并设置 96 / 128 / 192 kbps 码率 |
| 图片顺序 | 按添加顺序 | 可在素材列表中上下移动图片调整顺序 |

### 5.2 音频处理（共 1 项）

#### 🎧 7. 全能音频工坊（支持批量处理）

集音频格式转换、视频直接提取音频、精准音段截取、音量 50%~300% 增益调节与毫秒级淡入淡出于一体。

- **输入**：任意音频文件，**或直接上传视频文件**（系统将自动提取其伴奏或配音）
- **输出**：所选格式的音频文件

**常用预设**：

| 预设卡片 | 参数说明 | 推荐用途 |
| --- | --- | --- |
| MP3 标准音质（默认） | MP3 · 192 kbps · 原音量 | 通用音乐与设备播放 |
| 播客 / 人声增强 | MP3 · 128 kbps · 音量 150% | 放大录音中偏弱的人声音量 |
| 无损归档 | FLAC 无损 · 原音量 | 高保真音乐收藏与归档 |
| 视频原声提取 | M4A (AAC) · 192 kbps | 快速导出视频中的背景音乐 |
| 自定义 | 自由组合各项参数 | 专业音频参数调节 |

**参数说明**：

| 参数 | 默认值 | 范围 | 说明 |
| --- | --- | --- | --- |
| 输出格式 | MP3 | MP3、M4A (AAC)、WAV (无损)、FLAC (无损)、OGG、OPUS | 按播放设备与场景选择 |
| 音频码率 | 192 kbps | 96、128、192、256、320 kbps | 仅对 MP3 / M4A / OGG / OPUS 有效 |
| 开始时间 | 0 秒 | ≥ 0 | 音频截取起点 |
| 结束时间 | 0 秒 | 0 = 截取到尾部 | 音频截取终点 |
| 音量微调 | 100% | 50%、80%、100%、120%、150%、200%、300% | 低于 100% 降噪防爆音，高于 100% 显著提升音量 |
| 淡入时长 | 0 秒 | 0 ～ 10 秒 | 片头声音由静至大淡入时长 |
| 淡出时长 | 0 秒 | 0 ～ 10 秒 | 片尾声音由大至静淡出时长 |

**批量转码体验**：
- 支持批量添加音频/视频，列表项展示专属音符图标 `🎵`；
- 完成后提供「▶ 试听」按钮，可即时全屏弹出试听播放器。

### 5.3 图片处理（共 7 项）

| 网站与移动端优化 | WebP · 质量 75 · 最长边 ≤ 1280px · 抹除隐私 | 网页极致加载加速 |
| 极小邮件附件 | JPG · 质量 65 · 最长边 ≤ 1080px · 抹除隐私 | 邮件传输与表单快速上传 |
| 高清相册存档 | PNG 无损 · 原尺寸 · 保留元数据 | 原图归档与画质收藏 |
| 自定义 | 手动自由调节各项参数 | 个性化调色与定制 |

**参数说明**：

## 8. 常见问题 FAQ

**Q1：为什么第一次打开比较慢？**
A：页面内嵌了完整的音视频处理引擎（约 43 MB），首次打开需要解析，通常需要几秒到十几秒。之后浏览器会缓存，再次打开会快很多。

**Q2：上传后为什么没有显示时长和分辨率？**
A：系统正在读取文件信息，请稍等几秒。若长时间没有显示，可能是文件已损坏或格式不受支持，可尝试换一个文件或用其他播放器确认文件可正常播放。

**Q3：处理需要多久？**
A：取决于文件大小、功能和您的设备性能。经验参考：1 分钟 1080p 视频的"视频压缩"在普通笔记本上约需数分钟。"去除音轨"等不重新编码的功能则几乎瞬间完成。

**Q4：可以同时处理多个文件吗？**
A：目前一次处理一个任务。完成一个后，可以再上传下一个文件开始新任务。

**Q5：处理后的文件变大了，为什么？**
A：通常是因为输出格式为无损（WAV、PNG），或把有损格式（JPG）转换为了高质量设置。尝试降低质量参数，或选择压缩类功能。

**Q6：支持加密文件或 DRM 视频吗？**
A：不支持。受 DRM 保护的视频（如流媒体平台下载的内容）无法处理。

**Q7：支持中文文件名吗？**
A：支持。输出文件会沿用原文件名并附加功能后缀。

**Q8：为什么视频剪切后开头有一小段黑屏或画面跳动？**
A：使用"快速剪切"时，起点只能对齐到关键帧，可能出现偏差。改用"精确剪切"即可解决。

**Q9：手机上可以使用吗？**
A：可以，但手机内存有限，建议只处理小于 50 MB 的文件。

**Q10：为什么没有声音？**
A：请确认：① 输入视频本身有声音（在文件信息中查看"含音轨"）；② 使用的是"去除音轨"时，输出本来就是无声的。

## 9. 故障排查

### 9.1 顶部显示"FFmpeg 加载失败"

1. 点击顶部的 **"重试"** 按钮。
2. 刷新页面（F5 或 Cmd+R）。
3. 更换为 Chrome 或 Edge 的最新版本。
4. 若仍失败，请记录页面红色横幅中的错误信息，联系技术支持。

### 9.2 长时间停留在"正在初始化"或"正在加载 FFmpeg 核心"

这通常是设备性能或内存不足导致的：

1. 关闭其他浏览器标签页和占用内存较多的程序。
2. 等待数十秒，系统会在 **120 秒后** 给出超时提示。
3. 超时后点击 **"重试"**。
4. 仍不行时，尝试 **无痕窗口**（可避免浏览器扩展干扰）或更换浏览器。
5. 手机端可尝试重启浏览器，或换用电脑。

### 9.3 处理失败，出现红色错误提示

错误信息中可能包含以下内容，可据此判断原因：

| 错误提示 | 含义 | 处理方法 |
| --- | --- | --- |
| `Invalid data found when processing input` | 文件损坏或格式不支持 | 换一个文件，或先用播放器确认文件可播放 |
| `Unknown encoder` | 该输出格式在当前版本中不可用 | 换用其他输出格式（如 MP4） |
| `Output file ... does not contain any stream` | 输入不包含所需的声音或画面 | 例如对无声视频提取音频，属正常提示 |
| `Option loop not found` | 图片转视频的输入不是图片（例如误把 MP4 作为输入） | 新版本已禁止此操作；请选择 PNG / JPG / WebP 等图片作为输入 |
| `图片动态封面视频只接受图片文件作为输入` | 同上，新版本给出的中文提示 | 同上 |
| `结束时间必须大于开始时间` | 时间设置有误 | 修改结束时间 |
| `开始时间超出视频时长` | 起点超过视频总长 | 减小开始时间 |
| `无法获取音频时长` | 文件信息读取失败 | 重新上传文件 |

### 9.4 处理中途页面卡住

- 大文件转码耗时较长属正常现象，请耐心等待，**不要关闭页面**。
- 若进度条长时间不动，可点击 **"取消"**，然后降低分辨率、缩短时长后重试。
